# MANTEIGA · drum multi-fx

Multi-efeitos para bateria que corre no browser. Carrega um loop, ouve a demo ou processa uma entrada ao vivo (microfone ou interface de áudio) através de uma cadeia de efeitos — drive, tom, afinação e formante, ducking, reverb e mais — cada um com o seu bypass.

Online: [manteiga.monco.io](https://manteiga.monco.io)

## Usar

Abre o `index.html` num browser recente e escolhe **Loop**, **Demo** ou **Live**. O áudio é processado no próprio browser.
